# MSS Stockpoint (Prototype MVP)

Prototype PWA untuk Product Owner Warehouse Case Study. Data dan tarif hanya contoh.

## Peran
- **Supplier:** cari gudang, ajukan slot, lihat jatah dan stok, jadwalkan stok masuk, pantau order dan invoice
- **Ops MSS:** setujui atau tolak slot, tandai stok diterima, proses order
- **Toko:** lihat katalog Ready Stock dan pesan

## Alur demo
Supplier ajukan slot, Ops setujui, Supplier jadwalkan stok masuk, Ops tandai diterima, Toko pesan, Ops kirim, Supplier lihat hasilnya.

## Deploy (GitHub Pages)
1. Upload semua file di root repo
2. Settings, Pages, branch `main`, folder `/ (root)`
3. Buka `https://username.github.io/nama-repo/`

## Asumsi prototype
1 pallet = 50 dus, handling dan pengiriman satu tarif per order, gratis simpan 14 hari pertama, pilot hanya gudang MSS dan kategori Keramik.
